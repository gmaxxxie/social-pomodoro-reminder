# 🍅 社交網站番茄鐘提醒（15 分鐘，溫和模式）

一個用於社交網站的番茄鐘式時間提醒 Userscript。  
**只提醒、不阻擋、不強制**，幫助你覺察時間，而不是限制行為。

---

## ✨ 功能特色

- ⏱ 每 15 分鐘為一段番茄時間
- 👀 僅在「分頁可見 + 有焦點」時計算有效瀏覽時間
- 🔔 每完成一段進行一次提醒（不封鎖、不鎖屏）
- 🖥 右上角顯示段內計時器（已過 / 剩餘時間）
- 📊 右下角顯示今日累積段數與進度
- 🌙 每天 00:00 自動重置
- 🍪 使用 Cookie 儲存狀態，關閉瀏覽器後再打開仍可繼續計時

---

## 🍅 使用方式

- 1 段 = 15 分鐘「有效瀏覽時間」
- 當完成一段時，會收到提醒通知
- 是否休息或繼續瀏覽，完全由你自行決定

## 🧠 設計理念

本腳本的核心理念是 **時間覺察（Time Awareness）**：

> 不幫你做決定，只提醒你時間正在流逝。

適合不喜歡強制封鎖、但希望改善使用習慣的人。
